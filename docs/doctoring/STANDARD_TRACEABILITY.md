# Standards traceability

Initial adoption profile:

- xAPI 2.0: activity evidence is consumed from the Learning Record Store rather than recreated as LMS telemetry.
- cmi5 Quartz: launch/package compatibility for LMS-managed assignable units.
- LTI 1.3 + LTI Advantage: external tool launch, deep linking, roster/role, and grade/result integrations where applicable.
- QTI 3: assessment interchange; psychometric administration remains delegated to Psychometrics Commons when high-stakes measurement is required.
- CASE 1.1 and IEEE 1484.20.3: competency and learning-outcome interchange.
- Open Badges 3.0 and CLR 2.0: portable achievement credentials.
- ISO 29993, ISO 29994, ISO 29992, ISO/IEC 40180: service-quality operating profiles.
- ISO 30422 and ISO 10015: optional corporate L&D profile.
- ISO 21001: optional educational-organization operating profile.

Each conformance claim must name a precise revision and link executable evidence.
